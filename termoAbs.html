Abstração

Vídeo

Imagem

Explicação - Libras

Conceito

Criação de uma classe abstrata (incompleta) que foca apenas no que é importante para o sistema e descarta detalhes desnecessários.

Tradução

ABSTRAÇÃO SIGNIFICAR CRIAR CLASSE ABSTRATA.
CLASSE ABSTRATA NÃO-COMPLETA.
INFORMAÇÃO NÃO-IMPORTANTE DESCARTAR.
FOCAR SOMENTE IMPORTANTE FINALIDADE.



Exemplo em JAVA

declarando uma classe abstrata com o metodo mais importante

 public abstract class Calculadora {
                          abstract void ligar(); 
                          }
